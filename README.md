# Семейный архив здоровья

Приватное веб-приложение для хранения и анализа семейных лабораторных результатов.

Сейчас завершены четыре этапа: приложение работает в Docker с постоянной SQLite-базой, поддерживает общий вход, два семейных профиля, пакетную загрузку и локальное распознавание документов.

## Запуск

При первом запуске создайте локальный пароль и секрет сессии:

```bash
docker run --rm -v "$PWD:/app" -w /app node:24-bookworm-slim \
  node scripts/configure-local.mjs 'ваш-пароль'
```

Пароль должен содержать не менее восьми символов. Скрипт сохранит только его стойкий хеш и случайный ключ сессии в локальном `.env`. Этот файл не попадает в Git и Docker image.

Чтобы заменить существующую локальную конфигурацию, добавьте аргумент `--force`. После замены нужно перезапустить приложение.

Затем запустите приложение:

```bash
docker compose up --build -d
```

Откройте [http://localhost:3000](http://localhost:3000).

Проверить состояние контейнера:

```bash
docker compose ps
```

Посмотреть логи:

```bash
docker compose logs -f app
```

Остановить приложение:

```bash
docker compose down
```

Обычная остановка не удаляет данные. Не используйте `docker compose down -v`: флаг `-v` удаляет постоянный volume вместе с базой и документами.

## Проверка обновления

1. Остановите приложение командой `docker compose down`.
2. Снова выполните `docker compose up --build -d`.
3. Войдите и убедитесь, что профили и история измерений сохранились.

## Локальные данные

В контейнере база находится по пути `/data/archive.sqlite3`, а неизменяемые оригиналы — в `/data/documents`. В Docker Compose каталог `/data` подключён к именованному volume `health_archive_data`.

Поддерживаются PDF, PNG, JPEG и TXT: до 10 файлов за одну загрузку, не больше 20 МБ каждый и 90 МБ на весь пакет. Цифровые PDF и TXT читаются напрямую, изображения и сканированные PDF проходят OCR на русском, английском, французском, немецком и итальянском. Распознавание выполняется локально внутри контейнера и создаёт только черновик — в историю показатели пока не записываются.
