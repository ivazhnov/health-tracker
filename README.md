# Семейный архив здоровья

Приватное веб-приложение для хранения и анализа семейных лабораторных результатов.

Сейчас реализован первый технический этап: приложение запускается в Docker, а SQLite хранится в отдельном постоянном volume.

## Запуск

```bash
docker compose up --build -d
```

Откройте [http://localhost:3000](http://localhost:3000).

Проверить состояние контейнера:

```bash
docker compose ps
```

Посмотреть логи:

```bash
docker compose logs -f app
```

Остановить приложение:

```bash
docker compose down
```

Обычная остановка не удаляет данные. Не используйте `docker compose down -v`: флаг `-v` удаляет постоянный volume вместе с базой и документами.

## Проверка обновления

1. Запишите ID хранилища со стартовой страницы.
2. Остановите приложение командой `docker compose down`.
3. Снова выполните `docker compose up --build -d`.
4. Убедитесь, что ID хранилища не изменился.

## Локальные данные

В контейнере база находится по пути `/data/archive.sqlite3`. В Docker Compose каталог `/data` подключён к именованному volume `health_archive_data`.
